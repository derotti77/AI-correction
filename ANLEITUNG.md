# 🤖 KI-Korrektur Daemon

**Unsichtbares Hintergrundprogramm für automatische Textkorrektur!**

## 🚀 So funktioniert's

Das Programm läuft **unsichtbar** im Hintergrund und wartet auf dein Tastenkürzel.

### **Workflow:**
1. **⌘C** - Text kopieren
2. **⌘⇧K** - Daemon korrigiert automatisch
3. **Fertig!** - Korrigierter Text wird automatisch eingefügt

**Kein Interface, keine Fenster - läuft einfach im Hintergrund!**

## 📱 Starten

1. **Doppelklick** auf "KI-Korrektur" im Applications-Ordner
2. Terminal-Fenster öffnet sich (kannst du ignorieren)
3. **Fertig!** Programm läuft jetzt im Hintergrund

## ⌨️ Verwendung

1. **Text markieren und kopieren** (⌘C)
2. **⌘⇧K drücken**
3. **Automatisch wird der korrigierte Text eingefügt!**

## 🔧 Voraussetzungen

- **Ollama läuft**: `ollama serve`
- **Mistral Model**: `ollama pull mistral`

## 💡 Beispiel

1. Schreibe: "Das ist einn testt mit felern"
2. Markiere den Text und kopiere (⌘C)
3. Drücke **⌘⇧K**
4. Text wird automatisch zu: "Das ist ein Test mit Fehlern"

## ⚙️ Beenden

- **Strg+C** im Terminal-Fenster
- Oder Terminal-Fenster schließen
